# Camera App 0.5.11 — 3D folder-selection buttons

The Recording and Output folder selection controls now share a raised 3D appearance.

- Light-blue vertical gradient face
- Darker blue lower base/shadow
- Rounded corners and border
- Bold dark-blue text
- Subtle Android elevation
- Pressed state shifts the face downward and reduces the lower edge, simulating a physical button press

No folder-selection behavior, permissions, monitoring logic, or output logic was changed.
